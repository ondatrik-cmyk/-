# 📊 Комплексний командний аналіз логістики та складських запасів

Цей проєкт об'єднує аналітичні напрацювання всієї команди для оптимізації логістичних витрат та складських залишків підприємства.

---

## 🛠️ Структура об'єднаних файлів проєкту
Завдяки злиттю гілок, у репозиторій успішно інтегровано модулі аналітики від кожного учасника:
1. `data_loader16062026.py` — первинна обробка та завантаження очищених даних з бази `online_store.db`.
2. `Analize_inventory_new.py` — розрахунок оборотних категорій та залишків.
3. `Analize_shipments_AVG.py` — розрахунок середньої вартості та термінів доставки.
4. `Zalishki_ZERO.py` — скрипт пошуку неліквідних товарів («мертвого вантажу»).
5. `bukov80_...` — файли додаткового аналізу постачальників та витрат.

---

## 🚚 1. Результати аналізу логістики (за даними `Analize_shipments_AVG.py`)
На основі історичних даних замовлень розраховано оптимальних перевізників для ключових країн доставки:

* **USA:** Найдешевший — *United Package* ($23.45) | Найшвидший — *Federal Shipping* (4.2 дні)
* **Germany:** Найдешевший та найшвидший — *Speedy Express* ($14.80, 3.1 дні)
* **UK:** Найдешевший — *United Package* ($18.10) | Найшвидший — *Federal Shipping* (5.0 днів)

💡 **Компроміс для фінансистів:** Оскільки найдешевший перевізник зазвичай не є найшвидшим, бізнесу рекомендовано впровадити **гібридну модель**: регулярні поставки здійснювати дешевими компаніями, а термінові замовлення відправляти експрес-службами за рахунок покупця.

### 💰 Фінансовий ефект від оптимізації (Розрахунок економії):
* Фактичні витрати на логістику за рік: **142,560.00 $**
* Оптимальні витрати при виборі вигідних перевізників: **114,210.00 $**
* **Потенційна чиста економія для компанії:** **`28,350.00 $` (19.9% від бюджету)**

## 📦 2. Аудит складів та «Мертвий вантаж» (за даними `Zalishki_ZERO.py`)
Аналіз коефіцієнта оборотності товарних запасів виявив критичну проблему з накопиченням товарів без руху понад 150 днів.

* **Категорія найвищого ризику:** *Condiments* (приправи бренда *Chef Anton's*). Вони займають дефіцитне місце на складі, але мають нульову оборотність.
* **Рекомендація операційному відділу:** Негайно ініціювати розпродаж або включити ці товари як безкоштовні подарунки у маркетингові набори для вивільнення складських площ.
